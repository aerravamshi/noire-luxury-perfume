# NOIRÉ PARFUMS

Premium cinematic luxury perfume website built with a dark modern aesthetic.

## ✨ Overview

NOIRÉ PARFUMS is a high-end luxury fragrance landing page designed to attract international clients with cinematic visuals, smooth animations, and premium branding.

The website features:

- Dark luxury UI
- Cinematic hero section
- 3D rotating perfume bottle
- Smooth scrolling animations
- Premium typography
- Responsive modern layout
- Luxury fashion-film aesthetic
